# Define the two board roles

Type: grilling
Status: resolved
Blocked by:

## Question

What hardware acts as the Trigger Board and Playback Board in the first demo?

## Answer

Both roles use the same Tuya T5AI development board and the same attached display hardware. The roles are fixed by firmware/configuration for the demo: the Trigger Board initiates playback, while the Playback Board receives the reference and presents the media.
