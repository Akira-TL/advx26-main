# Set the media duration and synchronization target

Type: grilling
Status: resolved
Blocked by:

## Question

What duration and audio/video synchronization target defines the first demo?

## Answer

Each Media Package contains one video and one audio asset with equal duration. The maximum duration is 30 seconds.

Playback should appear synchronized, with approximately 100–300 ms audio/video error acceptable for the competition prototype. Strict long-running clock synchronization is out of scope because clips are short and bounded.
