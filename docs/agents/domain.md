# Domain documentation

This repository uses a single domain context.

## Read before changing behavior

- `CONTEXT.md` for canonical domain terms
- `docs/adr/` for hard-to-reverse architectural decisions

Create ADRs only for decisions that are costly to reverse, surprising without context, and based on a genuine trade-off.

`CONTEXT.md` is a glossary, not a specification. Implementation details belong in Wayfinder tickets, specifications, ADRs, source code, or tests.
